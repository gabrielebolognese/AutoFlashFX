The truth nobody tells you about /init.

If you open Claude Code on the same repo every day, you know the drill: new session, and you explain how your tests run all over again.

Run /init and Claude analyzes your codebase and writes a starter CLAUDE.md: build commands, test instructions, conventions. It gets read every session.

The docs say the work from there is mostly removing lines, and to keep it under 200. If Claude could find it and would look for it, delete it.

Then add by hand what the code can't tell it: exact test commands, any misleading code, decisions made outside the repo, anything you corrected twice.

It's context, not enforcement, so hard rules belong in a hook. One command starts it. You finish by deleting.
